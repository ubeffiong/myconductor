§ 14 · Interpretation

What this report does and does not say

Numbers are only useful when their limits are stated. These interpretations are written to be auditable: each claim points at a specific cell or table above.

I.2The false-susceptible asymmetry

Very major errors — a drug wrongly cleared for use — are not evenly distributed. They concentrate in bedaquiline (3), amikacin (3), moxifloxacin (2), ethambutol (2). A false susceptible call puts a patient on a failing regimen, which is how amplified resistance and onward transmission are made; a false resistant call costs a usable drug. The two are not interchangeable and this report never averages them into one figure without also showing them apart.

Hypothesis to test: whether these cluster in one lineage or in isolates carrying non-canonical variants. The lineage section addresses the first; the alignment view allows direct inspection.

I.5Drugs this pairing cannot evaluate

Evaluating a call needs a genotypic side to make it from and a phenotypic side to score it against. These lack one or both: delamanid (missing phenotype); cycloserine (missing both). cycloserine is absent from both the catalogue and the phenotype source, so no pairing of these two can evaluate it at all. Listing only the drugs that happen to be covered would read as a complete panel.

The two absences have different remedies: no catalogue entry means nothing can be predicted; no phenotype means a prediction cannot be checked.

I.6What this report does not claim

No component here has been clinically evaluated, and no sensitivity, specificity or error rate in this document should be read as a validated performance characteristic of a diagnostic. Where a benchmark figure is shown it is measured against the reference phenotype named in the methods grid, on the cohort described there, and nowhere else.

Every panel with no data renders an empty state rather than a generated one. A blank section in this report means the run produced nothing for it.
§ 15 · Methods & Caveats

How these numbers were produced

Cohort

12 sample(s) analysed in this run. 10 drug(s) reported.

Assay panel

Synthetic comprehensive TB panel 2026.1 (targeted-amplicon), 20 locus/loci; locus list NOT verified against the manufacturer's design. A locus the panel does not target is never callable, whatever a coverage file claims.

Reference phenotype

Synthetic paired MGIT and microdilution demonstration dataset

Call ontology

Six states: resistant, susceptible, indeterminate, not assessed, no call, unsupported. Only catalogued and phenotypic evidence may establish RESISTANT; coverage is a precondition for SUSCEPTIBLE.

Coverage

Callable-locus evidence from outside the variant list. Depth floor 10x, callable-fraction floor 0.95. Source: depth-table restricted to Synthetic comprehensive TB panel 2026.1.

Organism profile

mtbc 0.2.0-illustrative, against NC_000962.3.

Tool version

Analysis fingerprint

What this is not

A research and decision-support scaffold, not a clinical device. Every call requires review by a qualified clinician against phenotypic testing and current treatment guidelines.

Data guide · Human and machine use

What each downloadable dataset contains

The main report presents evidence as cards, tables, charts, and explanations. Downloads retain stable field names for machines. No private endpoint or external content is required to read or export this report.

Full report (JSON)

Run identity, six-state calls, evidence composition, callable loci, observed variants, validation context, cohort context, and audit events. Missing measurements remain null or absent.

Call matrix (CSV)

One row per sample and one column per drug. Values retain the six states. Susceptible is valid only when the report records callable resistance loci.

Benchmark (CSV)

Coverage, errors, sensitivity, specificity, predictive values, denominators, and estimability by drug. Blank metrics mean the cohort could not support that estimate.

Variants (VCF)

Only coordinate-resolved variants observed in the evidence. The exporter never creates positions for variants that lack genomic coordinates.

Coverage and discordance

Tab-separated tables preserve callable-locus fractions and engine disagreements. Discordant calls remain visible and are never reconciled by majority vote.

Audit ledger (JSONL)

One append-only event per line, including actor, target, timestamp, and hash preview. An empty ledger is explicitly marked rather than represented as a successful audit.
